# Onboarding Override

## Goal

Reduce uncertainty and completion fatigue while preserving the premium cosmic identity.

## Rules

- Five steps maximum
- Progress always visible
- Back navigation always available
- Draft automatically persists locally
- Each step has one primary CTA
- Required validation is shown after attempted progression
- Experience can be skipped for early-career talent
- Skills require at least three signals
- Portfolio accepts either a project or an external professional link
- Review screen summarizes every section before submission
- Step transitions preserve left/right spatial continuity
- Main form uses one-column mobile layout and two-column desktop layout only where labels remain clear
